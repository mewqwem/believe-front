# Візуальні сценарії BLUFF

У папці believe-front запусти фронтенд:

```sh
npm run dev
```

Відкрий http://localhost:3001/dev/game-scenarios — вибирай сценарії або натисни «Автопоказ». Кожен стан показується 8 секунд, показ повторюється по колу. Акаунти, MongoDB і бекенд не потрібні. Кнопки ігрових дій у демо не надсилають запитів; вибір карт працює.

Щоб дивитися автоматичні перевірки, в іншому терміналі:

```sh
npm run test:ui:open
```

Обери E2E Testing, браузер і game-scenarios.cy.js. Для запуску без вікна:

```sh
npm run test:ui
```

Cypress використовує вже запущений фронтенд і не запускає/не зупиняє сервери. Скриншоти — cypress/screenshots (виключені з Git). Для іншого локального порту: `npm run test:ui -- --config baseUrl=http://localhost:3002`.

Сценарії: 8 гравців на телефоні, вибір карти у свій хід, викритий блеф і тост, відключення, перший переможець, власна перемога та поразка. Це перевірки відображення підготовлених станів, а не повна партія і не перевірка серверного визначення переможця.

Маршрут /dev/game-scenarios повертає 404 у production. Запускай тести проти `npm run dev`, не проти публічного сайту.
